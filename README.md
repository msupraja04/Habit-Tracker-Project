# Habit Tracker

A full-stack Habit Tracker web application that helps users create, manage, and track their daily habits. The application provides progress tracking, streaks, points, badges, challenges, history, and statistics to encourage users to build consistent habits.

## 🚀 Features

- User Registration
- User Login and Logout
- Personalized Dashboard
- Create and Manage Habits
- Track Daily Habit Completion
- Habit History
- Current Streak Tracking
- Points System
- Badges and Achievements
- Daily, Weekly and Monthly Challenges
- Progress Statistics
- Notifications and Habit Reminders
- User Profile
- Responsive Web Interface
